# Dataset Dashboard

File `train_ready_dataset.csv` adalah salinan dataset final siap training dari:

`Final data scientist/03_final_datasets/main/train_ready_dataset.csv`

File `user_profile_features_schema.csv` adalah salinan schema profil user dari:

`Final data scientist/03_final_datasets/main/user_profile_features_schema.csv`

Salinan ini disertakan agar dashboard bisa langsung dideploy dari GitHub tanpa membawa dataset mentah.

`train_ready_dataset.csv` berisi data makanan, nutrisi per 100g, flag alergen, status halal, konteks waktu makan, pairing, dan image URL.

`user_profile_features_schema.csv` berisi sample fitur profil user seperti BMR, TDEE, target kalori, target protein, target lemak, target karbohidrat, dan allergy vector.
